## Preflight

After deployment, run:

```bash
npm run agent:registry:check -- --base-url=https://redqueen.space
```

This verifies metadata, OASF, x402 and a real MCP initialize handshake. It does not create or submit a transaction.

## Mainnet registration

The first registration must be explicitly signed by the project wallet. The intended SDK operation is:

```ts
registerAgent("https://redqueen.space/.well-known/agent-registration.json", {
  atomEnabled: false,
});
```

ATOM reputation remains disabled for the initial registration. It can be enabled later, but enabling it is one-way for the Agent Asset.

After confirmation:

1. Verify the returned Agent Asset and registration signature on Solana mainnet.
2. Set the project wallet as the operational agent wallet with a separate explicit signature.
3. Add `RED_QUEEN_AGENT_ASSET` and `RED_QUEEN_AGENT_REGISTRATION_TX` to Vercel.
4. Redeploy and rerun the live registry check.
5. Confirm the product state changes from `REGISTRATION PACKAGE READY` to `REGISTERED ON MAINNET`.

No private key belongs in the repository or browser-visible environment variables.
